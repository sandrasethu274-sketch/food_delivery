
# 🍔 Food Delivery Data Analysis

## 📌 Project Overview

The **Food Delivery SQL Analytics Project** is a MySQL-based data analysis project developed to generate meaningful business insights from food delivery data. The dataset includes information about users, restaurants, food items, menus, and orders.

The project focuses on analyzing **customer behavior, restaurant performance, food sales, revenue, payment methods, and monthly order trends** using basic and advanced SQL concepts.

## 🎯 Project Objectives

- 👤 Analyze food delivery orders and customer behavior.
- 💰 Understand customer spending patterns.
- 🏪 Identify top-performing restaurants.
- 🍕 Identify the most popular food items.
- 📈 Analyze revenue and sales performance.
- 🥗 Identify popular food categories.
- 💳 Analyze payment methods used by customers.
- 📍 Calculate average order value across cities.
- 🔄 Identify repeat customers.
- 📅 Analyze monthly revenue and order trends.
- 🔗 Apply Joins, Aggregate Functions, Subqueries, CTEs, and Window Functions.
- ⚙️ Create Views and Stored Procedures for efficient analysis.

## 🗂️ Dataset

The project contains:

- 👤 **Users** – Customer information
- 🏪 **Restaurants** – Restaurant details
- 📋 **Menu** – Menu and food item information
- 🍕 **Food** – Food-related details
- 🛒 **Orders** – Customer order information
